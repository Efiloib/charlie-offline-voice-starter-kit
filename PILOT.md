# Windows offline-assistant readiness pilot

## Purpose

This seven-day experiment measures whether anyone genuinely wants a narrowly scoped Windows offline-assistant readiness session based on this starter kit.

## Proposed session

- One 45-minute readiness session
- Stated future pilot price: **$35**
- Scope: review Windows version and basic hardware, identify realistic local speech/model options, and provide a concise readiness recommendation
- Not included: remote-control access, credential handling, financial tools, guaranteed compatibility, installation completion, or earnings claims

## Validation phase

This phase collects opt-in interest only.

- No payment is requested or accepted.
- Submission does not create a contract or guarantee selection.
- No unsolicited messages will be sent.
- The issue is public; never post secrets or sensitive personal information.
- Any follow-up will occur only after the project owner reviews the submission and explicitly approves contact.

## Success and failure criteria

- Primary success: at least one genuine, eligible opt-in issue during the seven-day window.
- Stronger signal: the submitter's stated problem fits the defined 45-minute readiness scope.
- Failure: no eligible opt-in, obvious spam only, or requests requiring unsafe/private access.

Traffic, views, stars, and model-generated claims are not revenue. Revenue remains $0 until a real payment is lawfully accepted and recorded.

## Privacy

The form requests only Windows version, CPU, RAM, GPU if known, timezone, and desired outcome. Do not provide passwords, tokens, recovery codes, addresses, recordings, payment details, private paths, or proprietary data.
