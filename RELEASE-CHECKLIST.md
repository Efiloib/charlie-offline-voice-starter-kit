# Release checklist

- [ ] `Verify-Release.ps1` passes.
- [ ] No credentials, tokens, private keys, personal names, private paths, or conversations.
- [ ] No binaries, installers, model weights, recordings, generated indexes, or logs.
- [ ] Every upstream dependency and model license is documented accurately.
- [ ] Example configuration contains placeholders only.
- [ ] Safety limitations and absence of warranties are prominent.
- [ ] A clean-machine installation test has been completed.
- [ ] Exact release archive checksum is recorded.
- [ ] Publication channel and final artifact have received owner approval.
